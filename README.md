# CHIRPY

## TL:DR

Chirpy is one of the projects at (Boot.dev)[https://boot.dev] to lear the Go language. It's a
knock off of Twitter that isn't terribly secure but it does teach a number of concepts including
the creation of a router, handlers, authentication, PostgreSQL backends, and the like. It was a
a lot of fun to create. Now I just need to do some serious refactoring and then think about
what I might want to add to it.
